# madchaz-lab toolbox

Reusable tools for the Madchaz homelab — MCP servers and automation that let AI
agents (opencode / Claude / …) drive lab infrastructure safely. Each tool lives
in its own folder with its own README (human) and agent guide.

## Contents

| Folder | What it does |
|--------|--------------|
| [`opnsense-mcp/`](opnsense-mcp/) | MCP server exposing the [OPNsense](https://opnsense.org) REST API — read state, and add/delete firewall rules, VLANs, NAT, services, backups, diagnostics. Includes a generic `opnsense_api` escape hatch for any documented endpoint. |

More tools will be added here over time.

## Conventions

- **Credentials are never committed.** Tools read keys/tokens from environment
  variables or private files (excluded via `.gitignore`). If a config needs a
  secret, use a placeholder (`CHANGE_ME`) — never the real value.
- **AI attribution**: every README notes that the work was generated by a
  human-guided local AI assistant.
